# Demo riff

`demo-riff.wav` is the dry DI loop the app plays when there is no interface
plugged in — the "Hear a demo" button on `NoInterfacePrompt`, routed through the
real rig by `AudioEngineController.startDemo()`.

**Why it exists.** Without it the app cannot be heard at all by anyone who does
not already own hardware, which includes every App Store reviewer. That is what
the 2.1 rejection came down to. AmpliTube ships the same thing for the same
reason — a demo section of pre-recorded riffs, so the app can be tried with
nothing but the phone.

**Why it is synthesised.** A riff that ships inside the binary is a licensing
question the moment it is a recording of somebody playing something. This one is
Karplus-Strong: a noise burst in a delay line one period long, low-pass filtered
each time round. Original by construction, genuinely a struck string rather than
an oscillator, and a dry DI — which is exactly what an amp sim wants at its
input. Generated by `research/demo-riff-generator.py`, which is repo-only and
not bundled.

E standard, 120 bpm, four seconds, palm-muted chugs into E5 / G5 / A5 / D5. The
last 60 ms fades so the loop seam is inaudible. Peak −6 dBFS, which leaves the
amp's input trim something to do; a DI that arrives near full scale does not.

**It is a placeholder.** Swap in a real DI recording whenever there is one worth
shipping. Nothing in the app knows the difference as long as the replacement
keeps the name `demo-riff.wav`, stays mono and stays 48 kHz.
